## Context
At Universal Music Group, I work as a Senior Fullstack Engineer contractor and lead frontend technical direction for a seven-developer team. We are migrating our application and pioneering the React implementation of a design system already used across 70+ Angular projects.

## My contribution
I own the frontend architecture and migration decisions, working with a UX/UI designer and UK-based professionals to translate established design standards into React. My responsibilities also include frontend state management, API contracts with backend teams, and delivery coordination.

## First adopter, with reuse in mind
Our application is the first adopter. The intent is to distribute the React components to other teams as needed; wider adoption is a future goal, rather than a completed rollout.
