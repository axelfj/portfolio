## The original project
A desktop exploration of pathfinding in a Pacman-style world. The project combines a generated grid, obstacles, collectible items, and an A* search implementation.

## Browser adaptation
The planned version would let visitors edit a maze and inspect the route search one step at a time. Keyboard and pointer controls would make the experience available without a microphone.
